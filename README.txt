Моя Бауманка 4.0.0 Alpha 2
React: навигация, сессия, контрольные. Остальные экраны пока используют совместимый legacy JS.
Сессия содержит пять исходных дисциплин. Контрольные хранятся отдельно в baumanka_controls_v1, включены в экспорт. Старые дополнительные записи переносятся в контрольные; нестандартные экзамены получают тип Другое.
Перед обновлением экспортируйте данные и отдельно сохраните библиотеку.
Локальная проверка: Node.js 22, npm install, npm test, npm run build, npm run preview.
Публикация после проверки: GitHub Pages Source = GitHub Actions; workflow в .github/workflows/pages.yml.
Сборка и браузерная проверка в среде автора не выполнены: зависимости npm недоступны.
